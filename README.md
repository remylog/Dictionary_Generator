# 辞書ジェネレーター (Dictionary Converter)

スプレッドシートから書き出したTSVやCSVファイルから、Mac標準のユーザー辞書（`.plist`）およびWindows MS-IME用のユーザー辞書（`.txt`）を同時に、または選択して一括生成できるクロスプラットフォーム対応のGUIアプリケーションです。

VTuberの名前、ファンネーム、固有の配信挨拶などをまとめて各OSのIMEに一括登録するのに最適です。

---

## 🌟 主な機能

- **マルチOS対応辞書生成**: Mac用の `.plist` 形式と、Windows MS-IME用の `.txt` 形式（Shift_JIS / 品詞「名詞」固定）の双方に対応。
- **出力対象OSの選択**: 画面上のチェックボックスで、必要なOS向けのファイルだけを選んで書き出し可能。
- **Mac仕様に完全準拠**: Mac標準のユーザー辞書インポート機能が要求する「よみ（shortcut）の五十音順・アルファベット順ソート」を自動で実行。
- **フォーマット自動判定**: 拡張子に応じて、タブ区切り（`.tsv`）とカンマ区切り（`.csv`）を自動的に判別して解析。
- **モダンなGUI**: 外観はOSのライトモード / ダークモードの設定に自動で連動。

## 🚀 ダウンロードと実行方法

### 1. 実行ファイルの取得
リポジトリ右側の **「Releases」** ページから、お使いの環境に合わせた最新バージョンのバイナリをダウンロードしてください。
- **Mac**: `dictionary-converter-mac.zip` (解凍すると `dictionary-converter.app` が現れます)
- **Windows**: `dictionary-converter.exe`

### 2. 初回起動時のセキュリティ解除手順
自作（未署名）アプリの仕様上、初回の起動時のみ各OSのセキュリティブロックを解除する必要があります。

- **🍏 Macの場合**
  1. ダウンロードした `.zip` を解凍します。
  2. `dictionary-converter.app` を普通にダブルクリックするのではなく、**「右クリック（二本指タップ） ＞ 開く」** を選択します。
  3. 警告が表示されますが、再度 **「開く」** をクリックすると起動します（2回目以降はダブルクリックで開きます）。

- **🪟 Windowsの場合**
  1. `dictionary-converter.exe` を起動します。
  2. SmartScreenの青い警告画面が出た場合、画面内の **「詳細情報」** というリンクテキストをクリックします。
  3. 右下に現れる **「実行」** ボタンをクリックすると起動します。

## 📖 使い方（データの準備とインポート）

### Step 1. 元データの作成（スプレッドシート）
Googleスプレッドシート等で、以下のような構成のシートを作成します。

| A列 (よみ) | B列 (単語) |
| :--- | :--- |
| たなか | 田中 |
| がいぶ | 外部 |

> ⚠️ **注意点**
> - **必ず1行目は見出し行（ヘッダー）にしてください。**（アプリが自動的にスキップします）
> - A列に「ひらがなのよみ」、B列に「変換後の正式名称」を入力します。
> - 作成後、**ファイル ＞ ダウンロード ＞ タブ区切りの値（.tsv）** または **カンマ区切りの値（.csv）** でローカルに保存します。

### Step 2. アプリでの変換
1. アプリを起動し、出力したいOSのチェックボックス（Mac用 / Windows用）をONにします。
2. **「ファイルを開く」** ボタンを押し、Step 1で用意した `.tsv` または `.csv` ファイルを選択します。
3. 選択したファイルと**同じフォルダ**に、変換された辞書ファイルが自動出力されます。

### Step 3. 各OSへのインポート

- **🍏 Macへの登録**
  1. Macの **「システム設定」 ＞ 「キーボード」** を開きます。
  2. 「テキスト入力」の項目にある **［編集...］** ボタンをクリックし、左メニューから **「ユーザー辞書」** を選択します。
  3. アプリから出力された **`[ファイル名].plist`** を、ユーザー辞書の単語一覧リスト（白い枠内）に**ドラッグ＆ドロップ**します。

- **🪟 Windowsへの登録**
  1. タスクバー右下のIMEアイコン（「あ」または「A」）を右クリックし、**「単語の登録」** を選択します。
  2. 辞書ツールウインドウが開いたら、メニューの **「管理」 ＞ 「テキストファイルからの登録」** を選択します。
  3. アプリから出力された **`[ファイル名]_windows.txt`** を選択して読み込ませます。
